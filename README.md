This project implements an automated bedroom environment system using an STM32 L432KC microcontroller. The system monitors motion, temperature, humidity, and ambient light, then adjusts devices such as a cooling fan and LED lighting using PWM control. When no motion is detected, the microcontroller enters a low-power mode to reduce energy consumption.
To demonstrate the design within the 5-week project window, the system was built and tested in a small-scale model of a bedroom. All sensors (SHT31, BH1750, HC-SR501) communicate over I2C or digital input, and the fan/LED outputs respond dynamically to real-time sensor data. An OLED display was planned for system feedback, but integration issues led to using UART output instead.
